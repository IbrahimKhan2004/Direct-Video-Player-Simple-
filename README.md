# Direct-Video-Player-Simple-

Simple online video player. Paste a direct video link and play it in the browser, powered by [movi-player](https://moviplayer.com/).

## Features
- Plays MKV, MP4, AVI, MOV, FLV, MPEG-TS, WebM
- Codecs: H.264, HEVC, AV1, VP9 and more; HDR10 / HLG
- Multiple audio tracks (Hindi auto-selected if found)
- Built-in subtitles plus local `.vtt` file support
- Resume playback per video link
- Apple-style dark/light UI

## Usage
1. Open `index.html` (or host the files on any static host).
2. Paste a video URL and press **Play Video**.

## Notes
- The video URL must allow CORS and range requests, otherwise playback or seeking will fail.
- Everything runs in the browser. Nothing is uploaded.
